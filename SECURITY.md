# Security Policy

## Supported Scope

This repository contains a limited open-source subset of DAMIAO TECH AI. Security reports should relate only to code and behavior present in this public repository.

## Reporting a Vulnerability

Please do not publish sensitive vulnerability details in a public GitHub Issue.

Instead, use GitHub private vulnerability reporting if it is available for this repository. If private reporting is unavailable, open a public Issue containing only a brief non-sensitive description and request a private follow-up channel.

Please include:

- Affected component or file
- Reproduction conditions
- Expected and observed behavior
- Potential security impact
- Any suggested mitigation, if known

Reports concerning private DAMIAO TECH AI components that are not present in this repository are outside the scope of this public project.
